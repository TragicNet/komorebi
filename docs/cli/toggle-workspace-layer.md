# toggle-workspace-layer

```
Toggle between the Tiling and Floating layers on the focused workspace

Usage: komorebic.exe toggle-workspace-layer

Options:
  -h, --help
          Print help

```

Toggle the floating layer on top of the intact tiling (base) layer. Turning the
floating layer on raises all floating windows above the base layer without moving
any of the tiled windows; turning it off lowers the floating windows back below
the base layer.
